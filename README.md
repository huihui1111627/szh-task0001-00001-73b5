# 城市隧道通风与火灾疏散推演平台

零依赖（Node.js 内置模块）的隧道火灾通风与人员疏散推演系统。推演引擎在浏览器和 Node 中同构运行，服务端只负责静态托管与会话/方案持久化。

## 启动

```bash
npm start            # 默认 http://localhost:3000
PORT=8080 npm start
npm test             # 引擎物理/告警/回滚/重放确定性测试
```

## 功能

### 1. 隧道运行场景（连续展示）
- 24 个 50m 区段、双向车道，连续渲染车辆分布、烟雾浓度、能见度、温度、纵向风速。
- 烟雾箭头随风场指示蔓延方向；颜色表示正常/预警/危险/致命四级。
- 实时展示 5 台射流风机与洞口/横通道状态；点击任一区段弹出该区段烟雾、能见度、温度、车辆数、风机/通道状态，以及该区段每个受影响人员的状态和撤离 ETA。

### 2. 推演控制
- 可设置起火位置（0–23 区段）、火势等级（Ⅰ/Ⅱ/Ⅲ，决定热释放与持续时间）、交通密度（低/中/高/拥堵，决定车辆与人员规模）。
- 启动、暂停、单步，1×–8× 速度切换；运行中可随时调整任一风机方向（←/关/→）或关闭/开放疏散通道。
- 每次决策都写入决策时间轴；物理模型依据新的风场和通道拓扑重算烟雾扩散、人员路径和撤离时间。

### 3. 方案对比
- 任意时刻可将当前处置（决策序列）存为命名方案，可保存多个。
- 勾选 2–4 个方案后同步回放：撤离进度、受困人数、危险区段范围三条曲线随统一游标联动；汇总表对比撤离率、被困人数、预计完成时间。
- 风机对射冲突（紊流滞留区段）、出口不可用（服务区段与滞留人数）、人员被困（连续区段分组）均在画布虚框、右侧告警、顶部横幅和对比表中突出原因与影响范围。

### 4. 中断恢复
- 推演状态每 2 秒（及关键操作后）原子写入服务端 `data/session.json`，页面刷新或服务重启后自动恢复到最近有效状态并提示保存时间。
- 所有命令先校验后生效：非法操作（如关闭唯一逃生通道、起火后修改密度）整体拒绝，状态回滚到操作前并 toast 说明原因。
- 在时间轴上点选任意历史时刻可「从此节点继续」，引擎确定性重放到该节点并打上分支标记，之后的决策形成新分支。
- 服务端不可用时自动降级到浏览器 localStorage，功能不中断。

## 模型概要

- 时间步长 10s/tick；烟雾用风场平流 + 双向扩散 + 沉降，温度按热扩散与环境散热更新，能见度 `30/(1+12×烟雾浓度)` m。
- 射流风机对 ±2 个区段施加方向推力；反向且间距 ≤4 个区段（200m）判定对射冲突。
- 人员在起火后离车，按 BFS 到最近可用出口移动，步行速度随高温、低能见度衰减；温度 ≥100℃ 或无可达出口判定被困。
- 全部随机数由种子 `mulberry32` 生成，相同种子+决策序列的重放结果逐帧一致。

## 目录

```
public/
  sim/constants.js     物理/场景常量与阈值
  sim/engine.js        确定性推演引擎 (浏览器/Node 通用)
  js/api.js            会话/方案持久化 (fetch + localStorage 降级)
  js/render.js         隧道、时间轴、指标、区段详情渲染
  js/compare.js        多方案同步回放与对比图表
  js/app.js            状态编排、推演循环、回滚、恢复
server/
  index.js             静态托管 + REST API
  store.js             JSON 原子写入存储
test/
  engine.test.js       引擎单元测试 (8 组)
  ui-cdp.js / ui-cdp2.js / ui-cdp3.js  Chrome CDP UI 集成测试
data/
  session.json         当前未完成推演快照 (自动生成)
  plans/               保存的处置方案 (自动生成)
```

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST/DELETE | `/api/session` | 读取/保存/清除当前推演快照 |
| GET/POST | `/api/plans` | 方案列表 / 保存方案 |
| GET/DELETE | `/api/plans/:id` | 读取/删除单个方案 |
